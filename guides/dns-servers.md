Всем приветик! Данная инструкция направлена получения доступа к нейросетям, которые сами себя не дают использовать в РФ.
Тут совсем просто! Тут будут написаны dns-сервера, которые обходят блокировки нейросетей и пару других сервисов.
Сразу отвечу на возможный(е) вопрос(ы), которые могут возникнуть.

С файлом hosts раньше удобный способ был. ## Давай к сути?

Хорошо. https://www.comss.ru/page.php?id=7315 на этой странице вы сможете более подробнее ознакомиться с нашим первым dns-сервером с именем "Commss-dns".

1. 83.220.169.155 и 212.109.195.93 - для ipv4. Обычно подходит для Виндовс и Линукс.

2. dns.comss.one и tls://dns.comss.one - для Андроида и Линукса соотвественно.

3. https://dns.comss.one/dns-query - для браузера, либо для DOH в виндовс (начиная с 11 винды есть встроенный DOH).
