## Windows / Linux / Android

| Название | Описание | Платформа|
|----------|----------|----------|
|[**Idle Slayer**](./guides/idleslayer.md)|Обход блокировки серверов (Сихронизация с облаком)| Windows, Linux
|[**Zapret**](./guides/Zapret.md)|Средство для обхода DPI| Windows, Linux, Android
|[**Файл Hosts**](./guides/Hosts.md)|Простая правка системных файлов. Самый простой способ для браузеров| Windows, Linux
|[**Bunny VPN**](./guides/Bunny_VPN.md)| Обычный бесплатный впн-расширение для браузера на основе хромиума| Windows, Linux
|[**INSTAVPN**](./guides/INSTAVPN.md)| Расширение-ВПН для Инстаграма. Для браузеров на хромиуме | Windows, Linux
|[**TG WS Proxy, Telegram WS Proxy Android**](./guides/TG_WS_Proxy.md)|Локальный прокси Telegram.| Windows, Android
|[**AmneziaWG**](./guides/AmneziaWG.md)|Это VPN на модифицированных конфигах WireGuard. Абсолютно бесплатный.| Windows, Android
|[**AmneziaVPN**](./guides/AmneziaVPN.md)|Простой клиент для быстрого запуска VPN по готовым ключам| Android
|[**Cyberportal X**](./guides/CyberportalX.md)|Бесплатный VPN-клиент со встроенным генератором конфигов WARP| Android
|[**Portal WG**](./guides/PortalWG.md)|Бесплатный VPN-клиент со встроенным генератором конфигов WARP| Android
|[**Portal WG lite**](./guides/PortalWGLite.md)|Бесплатный VPN-клиент со встроенным генератором конфигов WARP (для слабых устройств андроид)| Android
|[**Portal Tor**](./guides/PortalTor.md)|Это бесплатное приложение для доступа в интернет через сеть Tor| Android
|[**Portal Connect**](./guides/PortalConnect.md)|Бесплатный VPN| Android
